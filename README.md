# Hunter Game

A top-down shooter game where you fight against waves of enemies in a forest environment.

## Installation

1. Make sure you have Python installed on your computer
   - Download from https://www.python.org/downloads/
   - Recommended version: Python 3.9 or newer

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the game:
   ```bash
   python alien_shooter.py
   ```

## How to Play

### Controls
- WASD: Move character
- Mouse: Aim
- Left Click: Shoot
- 1-5: Switch weapons
- M: Use medkit
- ESC: Pause/Quit
- SPACE: Start game/Continue

### Weapons
1. Pistol (infinite ammo)
2. SMG
3. Assault Rifle
4. Shotgun
5. Rocket Launcher

### Game Features
- Multiple enemy types with different behaviors
- Weapon pickups and medkits
- Explosive barrels for tactical gameplay
- Minimap for navigation
- Wave-based progression
- High score tracking

### Tips
- Use the rocket launcher to destroy groups of enemies
- Collect medkits to heal when damaged
- Use trees as cover from enemy fire
- Watch your ammo count for special weapons
- Shoot explosive barrels near enemies for area damage

## Requirements
- Python 3.9 or newer
- Pygame library (installed via requirements.txt)

Enjoy playing!
